`web_search` discovers text sources (title, URL, snippet, date) for a query. It does not fetch page bodies and returns no image or thumbnail assets. Known URLs/programmatic data → `read`, which fetches one URL and decodes images only in that page. There is no image-search or web-fetch tool: NEVER call a nonexistent `web.image`/`web.fetch`, and NEVER invent an image or thumbnail URL; a search result URL is a page, not a direct image. Browser automation is available only through the eval `browser` prelude when this session enables it; it complements, not replaces, search and `read`. Query: site: or -site:, after: or before: YYYY-MM-DD, inurl:, intitle:, filetype:, "phrase", -term, OR.{{#if xSearch}} X posts/reactions → `site:x.com`, `site:x.com/<handle>`, or `from:<handle>`; `-from:<handle>` excludes.{{/if}} Prefer primary sources; MUST link citations.
